05 / LOCAL MODEL VALIDATION
本地金融模型的验收与回归基线
量化信号模型验证推理一致性与投资效果；本地金融 Agent 可沿用任务与评分器，评估工具执行和端到端研究能力。
数据时点：防止未来信息泄漏
9 个 PIT 截断日期重放，验证公告与修订到达前后的历史预测一致性，约束本地特征流水线。
冻结推理：核对上线版本
独立重放 6 个部署成员与 8 个关键候选，核对 checkpoint、融合结果及篡改拒绝，支持版本追溯。
输入变化：验证模型响应
覆盖实体与行序、财务、估值、市场、行业五类扰动，为数据接口改动提供回归检查。
组合落地：复算交易与约束
独立核对 NAV、费用、容量拒单与仓位约束，验证信号到组合的执行链路。
跨期效果：识别部署短板
58 个样本外信号日、57,493 个参考键完整覆盖；微观路线与弱年度收益仍不达标，需继续研究验证。
Agent 选型：建立同条件对照
可固定任务、工具权限、时间预算与评分口径，对比本地基座、微调版本和 Agent 流程的分项表现。
现有记录为 GPT-5.6-Sol 评测，尚无本地大模型实测。4 CPU / 8 GB 是任务容器配置，不代表大模型推理资源需求。



06 / FROM BENCHMARK TO TRAINING
将执行证据转化为训练监督
终端任务提供环境、工具反馈与结果奖励，可用于工具调用、长程执行和金融研究能力训练。参数更新需接入训练系统。
RSI / RECURSIVE SELF-IMPROVEMENT
RSI：持续更新与独立验证
由失败诊断生成训练数据或改进策略，经模型或 Agent 更新，再在未接触任务上验证能力增量。
① 冻结任务并运行已有：任务、环境、参考解与模型记录
② 定位能力缺口已有：分项奖励与样本外结果
③ 生成并筛选训练样本待做：修复分支、成功轨迹与专家复核
④ 更新模型或 Agent待验证：参数、策略或工具流程更新
⑤ 新任务独立复测待做：未用于训练的任务族与隐藏验收
独立验收：用于训练或修复的任务转入开发集，按任务族、时间和数据实例另留测试集。本案例未提供模型更新及训练后增益证据。
